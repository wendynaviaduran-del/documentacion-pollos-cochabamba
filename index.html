1. Introducción y Objetivos

1.1 Introducción

El presente proyecto implementa la integración de las áreas operativas de Ventas, Almacén/Cocina y Contabilidad de la empresa Pollos Cochabamba. La arquitectura se basa en un servicio web API REST desarrollado en Python con Flask, permitiendo el intercambio bidireccional de información mediante formato JSON sobre el protocolo HTTP en red local.

1.2 Objetivos

  • Desarrollar una API REST centralizada para la gestión de productos, inventario y ventas.
  • Sincronizar el inventario en tiempo real descontando automáticamente el stock tras cada venta.
  • Conectar las áreas de Caja, Almacén y Contabilidad en red local LAN mediante direcciones IP (`0.0.0.0:5000`).

2. Integración Empresarial entre Áreas

La API actúa como el núcleo del sistema recibiendo solicitudes de las distintas áreas:

  • Caja / Punto de Venta: Envía peticiones POST /api/v1/ventas para procesar cobros en Bolivianos (Bs).
  • Almacén / Cocina: Consulta disponibilidad mediante GET /api/v1/productos y reabastece stock con PUT /api/v1/productos/<id> o entradas de inventario.
  • Contabilidad: Consume GET /api/v1/ventas para extraer los ingresos totales en Bs para el balance diario.

3. Documentación Técnica de Endpoints (Rutas de la API)

3.1 Gestión de Catálogo e Inventario

Método Ruta / Endpoint Descripción
GET /api/v1/productos Consulta el catálogo completo de combos y piezas.
POST /api/v1/productos Registra un nuevo producto o combo en el menú.
PUT /api/v1/productos/<id> Modifica precio en Bs o reabastece el stock.
DELETE /api/v1/productos/<id> Elimina o desactiva un producto mediante su ID.

3.2 Gestión de Ventas

Método Ruta / Endpoint Descripción
POST /api/v1/ventas Registra una venta y descuenta inventario automáticamente.
GET /api/v1/ventas Consulta el historial completo de ventas realizadas.
PUT /api/v1/ventas/<id>/pagar Modifica el estado de la venta a PAGADA.
PUT /api/v1/ventas/<id>/anular Anula la venta y reintegra las unidades al stock.

Estructura JSON de cada producto:

  "id": 1,
  "nombre": "Pollo",
  "categoria": "Carnes",
  "unidad_base": "g",
  "stock_base": 100000,
  "presentaciones": [
    {
      "id": 2,
      "nombre": "Kilogramo",
      "factor_base": 1000,
      "precio_bs": "25.00"
    }
  ]
}

Catálogo de Prueba Base

  • Combo Económico: 1 Pieza + Papas (Bs 18.00)
  • Combo Familiar: 8 Piezas + Papas + Bebida (Bs 85.00)
  • Balde Cochabamba: 12 Piezas (Bs 110.00)

5. Flujo de Trabajo en Ventas

  1. Petición: El cajero envía POST /api/v1/ventas con empleado_id y los detalles del pedido.
  2. Validación: La API verifica que el producto no esté vencido y que el stock_base sea suficiente.
  3. Cálculo y Descuento: Multiplica la cantidad por el precio unitario en Bs y resta automáticamente del inventario.
  4. Respuesta: Retorna confirmación HTTP 201 Created con el desglose del cobro.
